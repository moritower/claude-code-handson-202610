# サンプルアプリ: マーダーミステリー公演 予約システム（スターター）

このフォルダは AIDLC ハンズオンの題材です。
**わざと未完成**にしてあり、Claude Code と一緒に育てていきます。

## 動かし方

```bash
cd sample-app
npm install      # 初回のみ
npm start        # http://localhost:3000 が起動
```

開発中はファイル変更で自動再起動する `npm run dev` が便利です。

## テスト

```bash
npm test
```

## いま出来ること（スターターの状態）

- 公演一覧の表示（残席・満席バッジ付き）
- 予約の作成（残席チェックあり）
- 予約一覧の取得（`GET /api/bookings`）

## これから演習で作るもの（例）

- 予約のキャンセル（残席が戻る）
- キャンセル待ち（満席時の受付）
- 最少催行人数（催行決定の判定）
- 入力バリデーションの強化
- 自動テストの追加

## フォルダ構成

```
sample-app/
├── server.js          # Web サーバー本体（API）
├── src/
│   ├── booking.js     # ドメインロジック（純粋関数・テストしやすい）
│   └── store.js       # データ置き場（メモリ）
├── public/            # 画面（HTML / CSS / JS）
├── test/              # 自動テスト
└── CLAUDE.md          # Claude Code へのプロジェクト指示（フェーズ3で育てる）
```
