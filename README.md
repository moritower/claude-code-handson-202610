# Claude Code で学ぶ AIDLC ハンズオン（3時間）

AI 駆動開発ライフサイクル（**AIDLC: AI-Driven Development Life Cycle**）を、
**Claude Code** を使いながら体験する 3 時間のハンズオンコースです。

## 🎯 このコースのゴール

開発初心者が、次の 3 つを「手を動かして」体験します。

1. **AIDLC の全体像** を理解する（要件 → 設計 → 実装 → 運用の一連の流れ）
2. **要件・設計フェーズ** を Claude Code との対話で進められるようになる ★重点
3. **運用・自動化フェーズ** で反復作業を Claude Code に任せられるようになる ★重点

題材は **マーダーミステリー公演の予約受付・管理システム** です。
ゼロからではなく、最小限のスターターコードを Claude Code と一緒に育てていきます。

### なぜこの題材か

マーダーミステリーの公演には「**定員**」「**満席判定**」「**キャンセル待ち**」
「**シナリオごとの推奨人数**」といった“ドメインルール”があります。
こうしたルールを言葉にして仕様へ落とし込む過程は、
**要件・設計フェーズの練習**にうってつけです。

## 👤 対象者

- プログラミングを学び始めた方 / これから開発に関わる方
- Claude Code は初めて、という方
- ※ 特定言語の深い知識は不要です。ターミナルで文字が打てれば OK

## 🚦 進め方

1. まず `docs/00_setup.md` で環境を整えます
2. `TIMETABLE.md` の順に `docs/01` → `04` を進めます
3. 各章末の「✅ チェックポイント」で達成度を確認します

## 📦 事前準備（受講前にお願いすること）

- Node.js 18 以上（`node -v` で確認）
- Claude Code のインストールとログイン（`docs/00_setup.md` 参照）
- このリポジトリを手元に配置
