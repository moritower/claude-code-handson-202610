# 00. 環境準備（0:20–0:45 / 25分）

Claude Code を起動して、基本操作に慣れるパートです。
「難しいことは後回し」でOK。まずは動かしてみましょう。
この手順は Mac（macOS）向けです。

## 0-1. 事前チェック（3分）

ターミナルを開いて、次を実行します。

```bash
node -v      # v18 以上ならOK
npm -v
```

数字が表示されればOKです。表示されない場合は講師に声をかけてください。

## 0-2. Claude Code のインストールとログイン（7分）

npm のグローバルインストールは、インストール先の権限によって `EACCES`（書き込み権限エラー）になることがあります。ここでは [公式推奨のネイティブインストール](https://code.claude.com/docs/en/setup#install-claude-code) を使います。`sudo npm install -g` で回避しないでください。

```bash
curl -fsSL https://claude.ai/install.sh | bash   # インストール（初回のみ）
```

インストールが終わったら、新しいターミナルを開いて確認し、起動します。

```bash
claude --version   # バージョンが表示されればOK
claude             # 起動
```

`claude: command not found` が出た場合は、次を実行して再度確認します。

```bash
export PATH="$HOME/.local/bin:$PATH"
claude --version
claude
```

この PATH 設定は現在のターミナルだけに有効です。次回以降も使えるように、同じ `export` 行を macOS 標準のシェル zsh の設定ファイル `~/.zshrc` に追加してください。

権限エラーが続く場合や、`claude` の起動時に権限エラーが出る場合は、エラー全文（特に `EACCES` / `Permission denied` と対象のパス）を講師に見せてください。ディレクトリの権限を一括で変更しないでください。

初回は画面の案内にそってログイン（ブラウザが開きます）してください。
`>` のような入力欄が出たら準備完了です。

> 💡 すでにインストール済みの人は `claude` だけでOK。

## 0-3. サンプルアプリを開く（5分）

配布されたリポジトリの `sample-app` フォルダに移動して Claude Code を起動します。

```bash
cd aidlc-handson/sample-app
npm install     # 依存ライブラリの取得（初回のみ）
claude          # このフォルダで Claude Code を起動
```

## 0-4. まず動かしてみる（5分）

別のターミナル（またはタブ）で、アプリを起動します。

```bash
npm start
```

ブラウザで <http://localhost:3000> を開き、公演一覧が見えることを確認します。
1件、試しに予約してみましょう。

## 0-5. Claude Code の基本操作（5分）

Claude Code の画面で、次を順番に試します。
（`>` の後ろに文章を打って Enter するだけです）

1. **読ませる**:
   ```
   このプロジェクトが何をするものか、README.md と server.js を読んで
   3行で説明して
   ```
2. **聞く**:
   ```
   予約の残席チェックは、どのファイルのどこで行っている?
   ```
3. **小さく直す**:
   ```
   public/index.html のページタイトルの絵文字を 🕵️ に変えて
   ```

> 🔑 **ポイント**: Claude Code はファイルを勝手に書き換える前に確認を求めます。
> 内容を見て、良ければ許可（承認）します。これが「人がハンドルを握る」感覚です。

## 覚えておくと便利なキー操作

| 操作 | 意味 |
| --- | --- |
| `/help` | ヘルプを表示 |
| `Esc` | 生成を止める / 入力を中断 |
| `Shift+Tab` | 権限モードの切り替え（自動承認など） |
| `/clear` | 会話履歴をリセット（話が長くなったら） |
| `!` で始める | シェルコマンドをその場で実行（例: `!npm test`） |
